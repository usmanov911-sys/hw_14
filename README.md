## Реализованная функциональность

### 1. Архитектура классов и Наследование

- **`BaseProduct`**: Абстрактный базовый класс (ABC), задающий контракт для всех товаров (абстрактные свойства `price`, методы `__str__`, `__add__`).
- **`Product`**: Базовый класс товара, реализующий логику хранения данных.
- **`Smartphone`** и **`LawnGrass`**: Классы-наследники `Product`, расширяющие его специфичными атрибутами (производительность, модель, память, цвет / страна, срок прорастания).
- **`Category`**: Класс категории, управляющий коллекцией товаров.

### 2. Инкапсуляция и Валидация

- Приватные атрибуты `__price` и `__products` для защиты данных от прямого изменения.
- Геттеры и сеттеры для свойства `price` с валидацией:
  - Запрет установки цены `<= 0`.
  - Запрос подтверждения (`input`) при попытке снизить цену товара.
- Строгая проверка типов при добавлении товара в категорию (использование `isinstance()`).

### 3. Магические методы

- **`__str__`**: Человекочитаемое строковое представление для товаров и категорий.
- **`__repr__`**: Представление объектов для разработки и отладки.
- **`__add__`**: Сложение двух товаров для расчета общей стоимости на складе. Реализована строгая проверка через `type()`, запрещающая складывать товары разных классов (например, смартфон и траву).
- **`__iter__`** и **`__next__`**: Реализованы в классе `CategoryIterator` для возможности перебора товаров категории в цикле `for`.

### 4. Абстракция и Миксины

- Выделение общего поведения в абстрактный класс `BaseProduct`.
- **`ReprMixin`**: Миксин, который автоматически выводит в консоль информацию о классе и аргументах при создании любого экземпляра продукта.

### 5. Обработка исключений (Exceptions)

- Выбрасывание `ValueError` с понятным сообщением при попытке создать товар с количеством `0`.
- Метод `middle_price()` в классе `Category` для расчета средней цены, с безопасной обработкой `ZeroDivisionError` (возвращает `0.0` для пустой категории).
- **`ZeroQuantityError`**: Пользовательский класс исключения для обработки попыток добавления товаров с нулевым количеством (с использованием блоков `try` / `except` / `else` / `finally`).

### 6. Дополнительная функциональность

- Класс-метод `new_product` для создания товара из словаря с автоматическим объединением дубликатов (суммирование количества, выбор максимальной цены).
- Функция `load_products_from_json` для загрузки структуры категорий и товаров из внешнего JSON-файла.

### Магические методы
- `__str__` — строковое представление объектов
- `__add__` — сложение товаров (с ограничением по типам через `type()`)
- `__iter__`, `__next__` — итератор для перебора товаров категории

### Абстрактные классы и миксины
- **BaseProduct** — абстрактный базовый класс для всех продуктов

### Ограничения
- Сложение товаров возможно только для объектов одного класса
- В категорию можно добавлять только объекты класса Product или его наследников (через `isinstance()`)
